# Протокол Тестирования

Этот документ описывает обязательные шаги для тестирования функционала агентом.

## 1. Подготовка Сценария (ОБЯЗАТЕЛЬНО)
Перед запуском любых тестов (особенно браузерных), агент обязан:
1.  Составить подробный сценарий тестирования.
2.  Отправить этот сценарий пользователю на ревью.
3.  **Не начинать** тестирование до получения одобрения сценария.

## 2. Выполнение Теста в Браузере
При самостоятельном тестировании через `browser_subagent` или другие инструменты:
1.  Использовать тестовых пользователей (test/test2 и т.д.).
2.  Выполнять действия строго по утвержденному сценарию.

## 3. Диагностика Ошибок
Агент обязан проверять не только визуальный результат, но и технические детали:
1.  **Консоль браузера (Console Logs):** Проверять на наличие ошибок JS и предупреждений.
2.  **Сетевые запросы (Network Tab):** Проверять ответы API (статусы 4xx, 5xx), даже если визуально ошибка не отобразилась.

## 4. Отчет
После тестирования предоставить отчет:
*   Статус прохождения сценария.
*   Найденные ошибки (со скриншотами логов, если есть).
*   Логи консоли/сети, если были сбои.
